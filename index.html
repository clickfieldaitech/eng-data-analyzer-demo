Frequency spectrum (FFT)

Magnitude spectrum of the primary selected variable, detrended — most meaningful for cyclic or vibration-type signals.

Statistics

Correlation matrix

How every numeric column moves together — +1 means two variables rise and fall in lockstep, -1 means one rises as the other falls, near 0 means no relationship. Useful for spotting a hidden driver (e.g. temperature quietly affecting stress).

Spec compliance

Applies to the primary (first) selected variable. Leave blank to skip a bound.

Hold-phase pressure check (leak indicator)

Compares pressure at the start and end of the hold phase only — a real leak shows up as decay while pressure should be steady, not during ramp-up or controlled release.

Process capability (Cp / Cpk)

Uses the same spec limits above. Cp measures whether the process spread could fit inside spec if centered; Cpk accounts for how off-center it actually is — the number that matters for real capability.

SPC control chart (individuals)

Plots every reading in sequence against control limits (mean ± 3σ) computed from the data itself. Unlike a single pass/fail check, this catches a process drifting or shifting before any point actually goes out of spec.

Fatigue cycle counting (rainflow)

Counts full stress/load cycles in the primary variable using the rainflow method — the industry-standard way to turn irregular, real-world loading into a proper cycle count for fatigue-life calculations, instead of just reading peak-to-peak.

Fatigue life projection

Fits a linear trend to the primary variable across cycles and projects when it will cross an end-of-life threshold, compared against the target cycle count for this part.

Interpolate a value

Estimate the reading at any point between two measured samples — useful when you need a value at an exact time/cycle that wasn't directly logged.

Safety factor

Compares the worst observed reading on the primary variable against a material/design allowable you enter — the margin before failure.

Spring linearity & hysteresis check

Checks the loading curve stays linear (a nonlinear force/displacement curve usually means a manufacturing defect) and that the loading vs unloading hysteresis loop — the energy dissipated per cycle — stays under a set limit.
